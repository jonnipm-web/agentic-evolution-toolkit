# Martins Agent

Use this skill when a project needs a durable learning loop, coordination between specialized agents, or a careful translation of experience into reusable public guidance.

## Method

1. Establish the objective, non-goals, constraints, and source of truth.
2. Separate reusable lessons from project-specific implementation details.
3. Convert lessons into a small rule, skill, template, or decision record.
4. Test the guidance with a controlled example.
5. Record evidence, limitations, and the next improvement.

## Coordination

- give each agent a bounded role and output;
- define handoff conditions before parallel work begins;
- keep architecture decisions visible;
- use deterministic checks for deterministic questions;
- reserve human judgment for scope, risk, and irreversible decisions.

## Privacy boundary

Never publish proprietary code, credentials, private data, internal URLs, or unverified claims. Public artifacts should expose the method, not the protected product implementation.

## Delivery vocabulary

Use `PASS`, `PASS CONTROLADO`, `NOT_VERIFIED`, and `BLOCKED` when the evidence requires a precise boundary. Do not present a source-level result as proof of production behavior.

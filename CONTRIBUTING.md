# Contributing

Obrigado pelo interesse em contribuir.

## Antes de abrir uma issue ou pull request

- explique o problema ou a melhoria proposta;
- mantenha exemplos livres de credenciais e dados pessoais;
- preserve a distinção entre evidência local, CI, staging e produção;
- atualize a documentação quando alterar uma skill ou agente.

## Pull requests

Descreva o que mudou, como foi verificado e quais limites permanecem. Mudanças que ampliem o escopo ou introduzam comportamento destrutivo precisam de justificativa explícita.

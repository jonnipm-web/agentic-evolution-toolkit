# Code of Conduct

## Nosso compromisso

Queremos uma comunidade acolhedora, profissional e respeitosa para pessoas de diferentes experiências e origens.

## Comportamento esperado

- trate as pessoas com respeito;
- critique ideias, não pessoas;
- explique decisões técnicas com clareza;
- reconheça incertezas e limites das evidências;
- não publique segredos, dados pessoais ou material proprietário.

## Aplicação

Comportamentos abusivos, assédio, discriminação ou exposição indevida de dados não são aceitáveis.

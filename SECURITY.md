# Security

Este projeto contém instruções e templates para agentes. Eles devem ser revisados antes de serem usados em ambientes com acesso a código, dados ou ferramentas externas.

Não publique segredos, tokens, dados pessoais ou informações proprietárias em issues, pull requests ou exemplos.

Para reportar uma vulnerabilidade ou instrução perigosa, abra uma comunicação privada ao mantenedor quando essa opção estiver disponível. Não inclua credenciais no relatório.

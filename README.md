# Agentic Evolution Toolkit

> **Build in parallel. Evolve with evidence.**

Uma metodologia prática para evoluir projetos com agentes de IA usando três pilares:

1. **Arquitetura clara** — responsabilidades, contratos e limites explícitos.
2. **Desenvolvimento simultâneo coordenado** — trabalho paralelo sem perder coerência.
3. **Validação por evidências** — cada conclusão precisa de uma verificação proporcional ao risco.

Este repositório reúne skills, agentes, templates e exemplos anonimizados para apoiar projetos de software conduzidos por humanos e agentes especializados.

## Quick start

Leia [Os três pilares](docs/three-pillars.md), depois use o [Project Brief](examples/project-brief.md) para iniciar uma frente de trabalho. Para ver o método completo, percorra o estudo de caso em [`examples/complete-project`](examples/complete-project).

## O que existe nesta versão

- uma skill para orientar a evolução de projetos;
- um agente coordenador de arquitetura e execução paralela;
- um agente revisor de evidências e status;
- uma skill para decompor e coordenar frentes paralelas;
- um modelo de briefing de projeto;
- princípios para registrar decisões e evidências.

## Como este projeto se diferencia

O foco não é apenas gerar código. O foco é tornar o processo de construção observável, coordenável e verificável. Cada agente tem uma responsabilidade delimitada, cada frente tem uma saída definida e cada conclusão deve indicar a evidência que a sustenta.
